# TREND-CATCHER--EA
I developed an Expert Advisor (EA) for MetaTrader 5 with the help of ChatGPT, putting a lot of hard work into building and refining it.  The EA is based on a 9 EMA crossover strategy:  - It opens a BUY position when a candle closes above the 9 EMA. - When a candle closes below the 9 EMA, it closes the BUY position and opens a SELL position
